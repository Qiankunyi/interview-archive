# INTERVIEW档案アーカイブ

アニメ・ゲーム分野のインタビュー記事を，作品，クリエイター，テーマなどの関係から横断的に探索するための多言語アーカイブ・プロトタイプです。

「INTERVIEW档案アーカイブ」という名称は，英語の **INTERVIEW**，中国語の **档案**，日本語の **アーカイブ** を組み合わせたものです。インタビュー資料を言語の境界を越えて発見できるようにするという，本プロジェクトの多言語的な方向性を表しています。

## 公開プロトタイプ

- 公開URL: https://interview-archive.onrender.com/articles
- 公開状態の確認日: 2026年7月31日
- GitHub: https://github.com/Qiankunyi/interview-archive

一般利用者は，アカウント登録やログインを行わずに記事の閲覧と検索を利用できます。登録・編集・削除・インポートなどの管理機能は公開していません。

## 研究背景と目的

アニメ・ゲーム制作に関するインタビュー記事は，公式サイト，ニュース媒体，企業ブログなどに分散しています。記事の公開終了，サイト移転，URL変更などによって所在を把握しにくくなる一方，既存の検索手段では，作品名，クリエイター名，職種，制作テーマなどの関係を横断して探索することが容易ではありません。

本プロジェクトは，インタビュー記事の原文そのものを再配布するのではなく，書誌情報，作品・クリエイターとの関係，タグ，多言語要約および出典URLを構造化して記録することで，資料の再発見を支援することを目的としています。

本システムは京都情報大学院大学のマスタープロジェクト（MP0）における研究用プロトタイプとして開発しました。

## 主な機能

### 一般利用者向け

- 収録記事の一覧表示
- キーワード検索
- 新着順・古い順・タイトル順などの並び替え
- 作品別ページからの記事探索
- 記事詳細および日本語・英語・中国語要約の閲覧
- 原記事への出典リンクの表示

検索では，記事タイトル，クリエイター名，作品名，役割・職種，タグを単一の入力欄から横断的に検索できます。

### 管理者向け

- 記事の新規登録，編集および削除
- URLを用いた記事情報のインポート
- Gemini APIによる日本語・英語・中国語要約の生成
- 自動取得が成立しない場合の手動入力
- 複数記事の一括再インポート
- 管理画面および処理結果の確認

管理機能へのアクセスには認証が必要です。一般利用者向けの公開登録機能は無効化しています。

## 収録データ

2026年7月22日時点の評価用データとして，アニメ・ゲームにまたがる5つの作品・IP，13媒体から収集した実在のインタビュー記事28件を収録しています。

この28件は，インタビュー記事全体を網羅するものではありません。本研究では，収集対象として確認した32件のうち4件を収録できず，単一の公式アーカイブを母集団とする調査でも被覆率は35.3%でした。したがって，本プロトタイプが示すのは構築可能性と限定された収録範囲における探索可能性であり，資料の完全な保存や網羅的収集を証明するものではありません。

## 収集・要約処理

処理の基本的な流れは次のとおりです。

1. 管理者が記事URLを入力する。
2. Jsoupを用いて公開ページからタイトルや本文などを一時的に取得する。
3. Gemini APIを1記事につき1回呼び出し，日本語・英語・中国語の要約を構造化JSONとして生成する。
4. 管理者が取得結果と要約を確認する。
5. 書誌情報，要約，関連エンティティ，タグおよび出典URLをデータベースへ保存する。

JavaScriptによる動的描画，アクセス制限，HTML構造の差異などにより自動取得できないページについては，管理者が必要な情報を確認して手動で補完できます。

## 原文と著作権に関する設計

本システムは，取得した記事本文をデータベースに永続化しません。保存対象は，記事タイトル，関連する作品・クリエイター，タグ，要約および原記事のURLなどです。利用者が原文を確認する場合は，出典リンクから権利者または媒体の公開ページへ移動します。

この設計は，原文の代替物を提供するのではなく，資料の所在と関係を示して再発見を支援することを意図したものです。ただし，本プロジェクトにおける説明は研究上の設計方針を示すものであり，個別の記事利用について専門的な法律判断を示すものではありません。

## システム構成

| 区分 | 採用技術 |
|---|---|
| アプリケーション | Spring Boot 3.2.5 |
| 画面 | Thymeleaf / Bootstrap |
| データアクセス | Spring Data JPA / Hibernate |
| データベース | H2 Database |
| HTML取得・解析 | Jsoup 1.17.2 |
| 多言語要約 | Google Gemini API |
| ビルド | Apache Maven |
| 開発環境 | JDK 17 / Windows 11 |
| 公開環境 | Docker / Eclipse Temurin 21 JRE / Render |

## データの永続性

公開版はH2 Databaseを使用し，サーバー起動時に同梱された28件のシードデータを読み込みます。ホスティング環境の再起動や再デプロイ後も同じ評価用データを復元できる一方，公開環境上で追加・編集した内容を恒久的に保持する本番運用向けの構成ではありません。

## ローカルでの実行

### Javaで実行する場合

Java 17以降を利用できる環境で，次のコマンドを実行します。

```bash
java -jar interview-archive.war
```

起動後，次のURLへアクセスします。

```text
http://localhost:8080/articles
```

### Dockerで実行する場合

```bash
docker build -t interview-archive .
docker run --rm -p 8080:8080 \
  -e ADMIN_USERNAME=your-admin-name \
  -e ADMIN_PASSWORD=your-secure-password \
  -e GEMINI_API_KEY=your-api-key \
  interview-archive
```

秘密情報をREADME，ソースコード，Dockerfileまたはコミット履歴へ直接記録しないでください。

## 環境変数

| 変数名 | 用途 | 公開閲覧のみの場合 |
|---|---|---|
| `ADMIN_USERNAME` | 管理者のユーザー名 | 不要 |
| `ADMIN_PASSWORD` | 管理者のパスワード | 不要 |
| `GEMINI_API_KEY` | 三言語要約生成に用いるAPIキー | 不要 |
| `PORT` | アプリケーションの待受ポート | 省略時は8080 |

管理機能およびGemini APIを使用する場合は，必要な環境変数を実行環境側で設定してください。

## Renderへのデプロイ

本リポジトリにはRender Blueprint用の`render.yaml`とDockerfileが含まれています。Render上で本リポジトリを接続し，管理者認証情報およびGemini APIキーをRenderの環境変数として設定することでデプロイできます。

`render.yaml`では`/articles`をヘルスチェック対象に設定しています。

## AIツールの利用

- Gemini API：取得した記事に基づく日本語・英語・中国語要約の生成に使用しています。
- Claude Code：初期プロトタイプの画面およびコード作成と，開発中のコード記述支援に使用しました。その出力を出発点として，著者が設計を見直し，現行版を再構築しました。

アーキテクチャの選択，データモデル，権利処理に関する設計判断および動作確認は，著者の判断と操作に基づいています。

## 評価範囲と既知の制約

- 収録記事は28件であり，対象分野を網羅していません。
- 媒体名と掲載日は，現行データモデルでは独立した専用項目になっていません。
- JavaScriptで動的に生成されるページや自動アクセスを制限するサイトでは，自動取得できない場合があります。
- 要約品質について，人手による全件の意味的一致評価や利用者実験は実施していません。
- 認証機構とH2 Databaseは研究用プロトタイプのための構成であり，本番サービスとしての安全性・永続性・可用性を保証するものではありません。
- 公開URLは外部ホスティングサービスの稼働状況に依存します。

## 本研究との関係

本リポジトリの公開版は，2026年7月22日に授業内で発表したローカル版を基礎とし，同年7月23日から31日にかけて，一般利用者向け閲覧機能の公開，管理機能のアクセス制御および公開登録の無効化を行ったものです。

論文第4章の画面と評価結果は7月22日時点のローカル版に基づきます。オンライン公開に伴う調整は，評価対象となった主要機能および収録データ28件の内容を変更するものではありません。
